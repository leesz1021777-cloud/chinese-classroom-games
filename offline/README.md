# 紫藤花语文游戏中心 v0.2

下载本目录的 `wisteria-classroom-offline.zip` 并完整解压，按包内《使用说明.txt》运行。

新版包含490道原创练习、17个有题目的学习单元、七款游戏、随机答案位置、紫藤花闯关奖励和本地随机点名器。支持TXT、CSV、JSON名单导入，本轮默认不重复。

新增单元为原创拓展主题，不是已核实的2024新版教材目录；由教师确认适配性。升级会添加416道新题，保留旧版教师修改、停用、删除和设置。

推荐预装Node.js 24 LTS后运行启动课堂.bat，运行无需网络和npm。Windows入口及file协议直接打开仍需在实际电脑试用；本地HTTP、核心交互和随机点名已验证。名单仅在本机保存，完整JSON备份包含名单。

本分支同时包含完整开发源码、中文README和自动化测试。构建、lint、29项单元测试以及已修复问题的浏览器检查通过；file协议因云端管理员策略跳过。
