# 小宇宙语文游戏中心 · 离线交付包

本分支用于交付已构建的离线课堂应用。

下载同目录中的 `chinese-classroom-offline.zip`，然后完整解压。包含单文件 HTML、Node 本地服务器、Windows 启动入口和教师使用说明。

推荐预先安装 Node.js 24 LTS 后双击 `启动课堂.bat`。运行不需要网络或 npm。默认含74道原创示例题、七款互动游戏、教师题库管理、JSON/CSV导入、备份、课堂设置和小组计分。

直接双击 HTML 的持久化取决于浏览器；云端管理员策略禁止file协议测试，建议使用已验证的本地HTTP方案。Windows启动入口需在教师实际电脑试用。完整新版教材目录、下册题目与本地音频由教师确认补充。

若仓库为私有，必须登录有该仓库权限的GitHub账号才能下载。此分支只包含交付包，不包含尚未提交的完整开发源码。
