# 紫藤花语文游戏中心

面向小学一年级课堂的本地 React + TypeScript + Vite 应用。教师选课、抽题并在投影或触控大屏上主持游戏；无需登录、后端或付费 API。课堂游戏无需学生姓名；可选点名器支持教师导入名单，仅本机保存。所有应用资源随构建发布，课堂运行不访问 CDN、远程字体或在线音频。

## v0.2 本次更新

- 名称统一为“紫藤花语文游戏中心”，增加紫藤花主题、学习地图和课堂探险路线。
- 490道原创练习，17个有题目的学习单元（上册9个、下册8个）；新增为原创拓展主题，不冒充已核实的新版教材课序。
- 汉字、拼音、词语和声调选项每题、重试及重新开局都随机排列，缩减地鼠数量时也保证正确答案出现。
- 接受题目显式配置的多个通顺答案及时间词语序；跳过题目不会自动获得星星或搭桥。
- 增加森林寻字、车站旅行、天空花园、侦探印章、送信搭桥、词语小剧场和朗读舞台。
- 新增TXT、CSV、JSON名单导入及随机点名器，默认本轮不重复，支持滚动、手动停止、新一轮及多个班级。
- `contentRevision: 2`自动向旧版数据库添加416道新题，保留原题修改、删除、停用、课堂记录、设置及名单；同版本不重复更新或恢复已删除题目。

## 安装与开发

推荐 Node.js **24.19.0**（见 `.nvmrc`）与 npm **11.9.0**。最低 Node.js 版本 22.12.0。联网只用于首次安装开发依赖；教师发布版本不需要 npm。

```bash
cd /workspace/chinese-classroom-games
export npm_config_cache=/workspace/.npm-cache
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

普通 Windows 开发电脑在项目目录执行 `npm ci`、`npm run dev` 即可，不需要设置云端缓存路径。按照终端输出在本机浏览器访问开发服务器。

```bash
npm run test           # 题库、调度、拼音、备份与IndexedDB单元测试
npm run lint           # TypeScript / React静态检查
npm run build          # TypeScript编译检查 + Vite生产构建 + 单文件离线发布
npm run test:e2e       # Chromium交互测试，先运行build
```

浏览器测试需要 Playwright Chromium。普通机器可执行 `npx playwright install chromium`。本云环境已提供系统 Chromium，无需下载：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

测试会启动 5173 开发服务器及 4173 离线 HTTP 服务器。云端 Chromium 的管理员策略可能禁止 `file://`；该情形明确报告为跳过，仅单文件 HTTP 运行完成验证，不能视为双击模式测试通过。其他断言失败不会跳过。`npm run format` 用于格式化代码。

## 教师使用流程

1. **开始课堂**：选册次、单元、课文、游戏，选择当前课、单元已学课（按目录顺序至当前课）、跨课混合或专题范围；再选难度和题量。题量不足时提示实际数量，不重复补题。
2. **游戏乐园**：七款游戏共用题库。每轮可暂停、重试、跳过、手动切题，结束后显示结果和易错题，支持错题再次练习。错误反馈温和，不自动跳过。
3. **教师题库**：添加、编辑、复制、停用、删除、搜索，批量移动或复制到专题；预览不会写入课堂记录。题型与游戏自动匹配。
4. **我的课堂**：设置无计时或计时、音量、主题、动画速度、地鼠数量与换位速度、朗读速度与标点停顿。启用4—10个自定义小组时可手动加分、修正、撤销及清空，下一题可自动轮换。课堂结果只保存最近100轮，不记录个人成绩；点名名单由教师单独导入。

| 游戏         | 交互与教师配置                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------- |
| 汉字打地鼠   | 默认六个洞，按选项数调整；正确字必定出现。点击汉字作答，支持无计时教学。                                        |
| 拼音小火车   | 完整音节 / 汉字匹配，或依次选择声母、韵母、声调卡片。支持显式两拼、三拼数据；不拼接猜测音节。                   |
| 声调气球     | 四个气球对应四声；可使用题库文字提示和教师导入的本地音频。                                                      |
| 汉字侦探社   | 形近字选择、放大观察、教师指定字符或部件高亮、知识卡片；不生成笔顺。                                            |
| 词语搭桥     | 支持多个合理答案；正确后补上木板，人物前进。                                                                    |
| 句子排排队   | 点击选词、拖动已选词语或用左右移动按钮，显式多种正确排序。                                                      |
| 朗读节奏大师 | 自动逐字或逐词高亮（教师显式分段）、逗号及句末停顿，暂停、重播、逐字 / 逐句前进；教师标记完成，无自动语音评分。 |

音效由本机 Web Audio 合成，默认静音。音频须由教师导入，最大2MB/题，随 JSON 备份内嵌；本机浏览器须支持该音频格式。没有浏览器语音合成依赖。

**随机点名**：侧边栏进入点名器，导入名单后先预览确认。TXT每行一个姓名；CSV有表头，可选择姓名列；JSON支持姓名字符串数组或 `{"students":["姓名"]}`。最多30份班级名单、每班500人；同名条目按独立ID参与，允许同名学生各被点到一次。默认本轮不重复，全部点完后需主动开始新一轮；刷新页面重置本轮点名顺序。名单只存本机，但完整JSON备份包含名单，请妥善保管。

快捷键：F11 浏览器全屏，Esc 退出课堂（全屏时浏览器可能先退出全屏），左右方向键切题，空格暂停 / 继续。Tab 与 Enter 可操作按钮；输入框不触发课堂快捷键。触屏和鼠标均可点击大号答案卡。

## 离线发布与 Windows 本地运行

执行 `npm run build` 后生成：

```text
dist/                          普通静态部署版本
release/
  紫藤花语文游戏中心.html        单文件，JS、CSS、图标均内嵌
  serve.mjs                    零第三方依赖的本地HTTP服务器
  启动课堂.bat                 Windows启动入口
  使用说明.txt                 教师运行、更新和名单使用说明
  wisteria-classroom-offline.zip  自动打包的完整离线包
```

将整个 `release` 文件夹复制到教师电脑或 U 盘。可以尝试双击 HTML，但 **file 协议下存储行为因浏览器而异**，更换文件位置、浏览器或清理数据可能使题库不可见。界面会提示定期备份。此云环境禁止直接打开 file 协议，因此教师须在目标 Windows 浏览器自行确认双击模式。

**推荐可靠方案**：教师电脑预先安装 Node.js 24 LTS（首次安装需联网），之后双击 `启动课堂.bat`，浏览器访问本机 `http://127.0.0.1:4173`。保持启动窗口开启，关窗或 Ctrl+C 停止。无需 npm、无需再次安装依赖、运行完全离线。4173 已占用时先关闭其他程序，勿随意改端口，以免切换到不同的存储来源。也可执行：

```bash
npm run serve:offline
# 或在release目录：node serve.mjs
```

云端验证的是同一 Node HTTP 服务器在 Linux 上的运行；Windows 批处理入口生成但未在 Windows 系统实际执行。不包含 Node 安装程序或便携浏览器。

## 数据、备份与恢复

启动先检测 IndexedDB 是否可写，失败时尝试 localStorage；两者都不可用时显示**仅内存保存**警告。每次题库编辑均等待事务完成后才显示保存成功；写入失败时保留编辑器和原有数据，提示重试。损坏的原数据库不会被自动覆盖。请避免多个窗口同时编辑同一题库。

数据存储与浏览器、用户配置和 HTTP 来源绑定。开发端口5173、发布端口4173、file 协议各自拥有独立数据。升级前务必导出 JSON，切换来源后手动导入。清理浏览器数据会删除本地题库。

- **完整备份**保存教材、单元、课文、题目、设置、课堂记录、本地音频、本地名单及 `schemaVersion: 2`。
- **范围导出**保存选中册次、单元或课文的目录和题目，不包含课堂结果或点名名单。
- **合并导入**：同ID更新，无冲突数据保留；设置和结果保持当前版本。
- **完整覆盖恢复**：替换全部目录、题库、设置、结果；须二次确认。
- **指定范围覆盖**：仅替换题库页当前筛选范围的题目，其他范围保留，相关目录合并。
- 导入前展示新增、更新、移除摘要，校验所有字段、重复ID、答案存在性、层级和题型兼容性；任一错误阻止整批导入。
- 支持本项目 v1 同结构备份迁移：补齐 v2 设置字段及课堂记录。不猜测第三方或任意旧版本结构；未知版本拒绝导入。

CSV 使用 UTF-8（可带 BOM）。页面提供示例下载、字段映射、错误行定位、预览与确认。选择导入目标课文，导入时生成唯一ID；选项、答案、卡片用 `|` 分隔。必须修正所有错误行才能导入。

| 字段                          | 示例 / 要求                                                   |
| ----------------------------- | ------------------------------------------------------------- |
| prompt                        | 请找到“天”。（必填）                                          |
| type                          | choice / pinyin / tone / word / sentence / reading            |
| options, answers              | 天\|大\|人；天。支持多个答案。                                |
| difficulty                    | easy / normal / challenge，默认 easy                          |
| knowledge, explanation, notes | 知识点、解析、备注                                            |
| syllable, parts               | 合法音节如 biǎo；b\|i\|ao\|第三声                             |
| tone                          | 1—4，options须为1\|2\|3\|4，answers须一致                     |
| tokens, orders                | 小鸟\|在树上\|唱歌。；JSON `[[0,1,2]]`（CSV内用引号正确转义） |
| readingText                   | 朗读正文，可按CSV规范引用多行                                 |

朗读编辑器可用 `|` 明确分词（拼接须与正文一致），课堂设置中切换逐词模式；未分词的内容退回逐字模式。

图形编辑器的句子答案更直观：每行一种正确句子，用 `|` 分隔词语，无需编写索引。拼音校验检查显式合法音节表、声调位置和 ü 省写；**校验语法不代表题意已被审查**，教师仍需核对读音、题意、难度和教材适配性。

## 教材示例与教学边界

默认包含一年级上、下册2024年修订版数据模型。上册目录按委托方提供的课目清单创建：我上学了；第一单元《天地人》《金木水火土》《口耳目手足》《日月山川》；第二单元《a o e》《i u ü》《b p m f》《d t n l》。标注“已确认”表示清单中提供的示例课目，**不是本项目独立核验整册教材的声明**。

保留原有74道示例，新增416道原创练习，共490道。上册增加森林、天空四季、校园、家庭、词语、句子故事和拼音专项；下册增加春天、动物、关爱、伙伴、量词反义词、拼音、句子和朗读表达，共17个有题目的学习单元。新增课题均标记待教师确认，属于原创拓展主题。下册的正式教材目录仍需教师补齐，不套用旧版课序。所有朗读短文均为原创，不内置完整教材、图片或音频。

首次启动显示完整示例；旧版数据库升级时只加入新内容，不覆盖教师原有题目和设置，也不重新创建已删除的册次。内容版本标记防止同版本恢复已主动删除的新题。升级前务必备份，导入旧版备份后刷新页面即可执行新增内容升级。不要上传没有使用权限的教材节选或媒体。

## 代码结构与扩展

```text
src/
  domain.ts                 数据类型、Zod完整性校验、游戏兼容定义
  seed.ts                   原有示例与当前完整题库入口
  content.ts / phonicsPack.ts 新增主题及拼音专项、内容更新
  roster.ts                 名单导入校验与不重复点名
  adventure.ts              闯关路线、学习星星与奖励
  pinyin.ts                 合法音节与声调校验（不生成答案）
  services.ts               调度、答案判断、版本迁移、JSON/CSV导入导出
  storage.ts                IndexedDB事务、可用性检测与备用存储
  App.tsx                   四大功能入口与课堂 / 教师模式
  components/
    Setup.tsx               统一教材筛选和开课
    LearningMap.tsx          上下册学习主题地图
    RandomPicker.tsx         名单管理与随机点名
    Adventure.tsx            课堂进度和紫藤花奖励
    Bank.tsx / Editor.tsx    题库操作与图形编辑
    Catalog.tsx              教材、单元、课文和专题管理
    Classroom.tsx            设置与课堂结果
    Game.tsx                 共用课堂会话、计分、错题与快捷键
    scenes.tsx               七款独立游戏场景组件
    sceneRegistry.ts         场景注册表
scripts/                    单文件发布与跨平台本地HTTP服务器
tests/                      单元测试与浏览器交互测试
```

新增游戏时定义兼容题型、ID和展示信息，在场景注册表注册组件；复用统一筛选、题库校验、存储与课堂结果。新增教材可直接通过教师目录界面完成，不需要改游戏代码。未来 AI 辅助出题应先进入教师编辑器确认，再通过同一校验和保存流程进入正式题库。

## 尚需教师确认的事项

正式上下册新版目录、拓展主题的教学适配性、本地音频、实际课文节选及其使用权限由教师补充。单文件双击持久化、Windows启动入口、触控硬件和全屏键行为需在教室实际设备试用；本项目不进行自动语音识别评分，也不自动生成标准笔顺。
